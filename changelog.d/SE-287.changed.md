- **Manage Connections reads as sections instead of one long scroll.** The selected connection now has
  a fixed header — colour, name, provider, where it connects, its folder, and pills for read-only and
  AI access — that stays put while you scroll, so you always know what you are editing. Below it the
  form is grouped into *Identity*, *Connection*, *Advanced* and *Access*, with labels beside their
  fields instead of above them, which roughly halves the height of the form. The *Advanced* section is
  now subdivided by the groups each provider already declares (Security, Connection, SSH tunnel).
- **The connection colour is a named dropdown.** The same seven colours as before, but each one has a
  name you can read, and "no colour" says so instead of being an empty circle.
- **AI access is three radio buttons rather than a dropdown**, so which level is granted — and that a
  read & write level exists — is visible without opening anything. The fail-closed default, the write
  warning and the "never show to the AI" block are unchanged.
- **The action bar keeps one primary action.** Duplicate and Delete moved to a `⋯` menu next to Save;
  they remain one click away as icon buttons in the toolbar top-left. The empty panel now offers *New
  connection* and *New folder* instead of only a line of grey text.
- **Smaller form details from the design:** a port or timeout gets a short box instead of a full-width
  one, a dropdown no longer stretches across the whole column, file paths are shown in the monospace
  font, and the required-field marker is red rather than another grey character in the label. The
  collapsed *Advanced* header names what is inside it (Security · Connection · SSH tunnel), the test
  button reports its result with a green/red dot instead of grey text either way, and a selected folder
  shows how many connections and subfolders it holds.
