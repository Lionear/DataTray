- **SQL Server's Administration folder gets an Availability Groups entry**, next to Agent Jobs. It is
  badged `disabled` when Always On is switched off on the instance, and absent entirely on an
  edition/platform with no Always On support at all (Azure SQL Database, for instance).
- **An availability group now opens the same read-only dashboard SSMS shows**: group info (cluster type,
  quorum, listener, backup preference), a replica table, and a per-replica database table with a derived
  "behind by" column — the primary's last commit time minus the replica's, in seconds, next to the DMVs'
  own log-send/redo queue sizes in kilobytes. It is the only node dialog in DataTray that polls (every 10
  seconds): queue depth moves while you are looking at it, unlike everything else this dialog family shows.
  Creating or reconfiguring a group, and failing one over, stay out of scope for now (SE-247).
