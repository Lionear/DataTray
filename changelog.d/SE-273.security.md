- **A read-only AI connection can no longer be changed through a SQLite `PRAGMA`.** Over MCP, every
  `PRAGMA` counted as a read, so an AI client could run `PRAGMA user_version = 999` or
  `PRAGMA journal_mode = OFF` against a SQLite connection whose AI access was set to read-only, and
  change the database file. Only introspection pragmas without a value, such as `PRAGMA table_info('x')`,
  are still allowed there. Every other pragma is refused unless the connection is a sandbox.
