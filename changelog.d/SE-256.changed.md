- **SSH.NET updated to 2026.0.0.** The library behind SSH tunnels was on a version carrying a known
  vulnerability ([GHSA-q939-rpr3-3284](https://github.com/advisories/GHSA-q939-rpr3-3284)), which made every
  build report it. The flaw is in SCP file transfer — an API DataTray does not use, so nothing was ever
  exposed through it; this is about not sitting on a vulnerable version. Tunnels behave as before: password
  and private-key authentication, host-key fingerprint checking, and the forwarded local port are unchanged.
