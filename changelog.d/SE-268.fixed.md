- **The setup wizard's "Install…" now opens the Plugin Store on the engine you clicked.** Every tile
  under "From the Plugin Store" opened the store on whichever plugin its own list happened to show
  first, so clicking ClickHouse could land you on DragonflyDB.
- **Restarting from the Plugin Store during setup brings the wizard back.** The store's own "Restart
  now" ended onboarding on the way down, so an engine installed there left you with no wizard, no
  connection and no sign of what had been installed. The wizard now returns to the engine step and
  says which engine landed.
