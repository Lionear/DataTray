- **A transaction script with `UPDATE` statements no longer fails on MSSQL with "Incorrect syntax near
  the keyword 'ORDER'."** A `BEGIN…END`/`IF…END` block with a `SELECT` right before `END` and no `;`
  separating them (a common shape inside a conditional branch) confused the paging heuristic's
  semicolon-only statement splitter: it glued the trailing `SELECT` to the `END`/`COMMIT` that followed
  into one "statement" that still started with `SELECT`, which then wrongly got `ORDER BY … OFFSET …
  FETCH NEXT …` appended for query-result paging. `CASE…END` inside a real single `SELECT` is unaffected.
