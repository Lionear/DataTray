- **F5 on a Data tab refreshes the table instead of running an empty query.** Pressing Run/F5 while
  browsing a table sent the query editor's (empty) text to the server, which MongoDB and Elasticsearch
  rejected with "Empty query." while the grid kept showing the rows it had loaded before. It now
  reloads the current page, the same way Discard already did.
- **Truncating a table clears its open Data tab.** A truncate refreshed the object tree but left an
  open Data tab for that table showing the rows that had just been deleted; the tab now reloads along
  with the tree, as it does after any other change to the table.
