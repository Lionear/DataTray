- **SQL Server tables whose only uniqueness comes from a filtered (partial) unique index — a common
  soft-delete pattern, `UNIQUE (OrgId, ItemId) WHERE IsDeleted = 0` — can be edited again.** The grid
  showed these as read-only with "no primary-key column to identify rows", because SQL Server never
  reports a filtered index's columns as a key. Editing now recognises the index and ANDs its filter into
  every generated UPDATE/DELETE, so it can never touch a row outside the filter (e.g. a duplicate
  soft-deleted row sharing the same key values).
