- **Prometheus provider (PromQL, read-only).** Connect to a Prometheus-compatible endpoint and query
  it in PromQL from a normal query tab. The tree browses metrics (with their type and help text) and
  their labels; instant queries, range selectors (`up[1h]`) and subqueries all come back as a grid of
  `<labels…>, timestamp, value`. Read-only by nature — the HTTP API accepts no writes, so nothing in
  the grid or the DDL menus pretends otherwise. Debug-staged like the other `plugins/` providers.
