- **Managing connections no longer opens a separate window.** It is now a state of the main window: the
  sidebar switches from the schema tree to the connection/folder tree — with its drag-and-drop
  reordering and folders intact — and the connection form opens where the editor tabs are. Your open
  tabs are untouched underneath and come straight back when you close it with the × next to *Manage
  Connections*. Nothing was lost in the move; the tree, the form and every action are the same ones,
  just in the window you were already looking at.
- **Both sidebar states now look like one sidebar.** The connection tree kept the roomier row height and
  larger icons it had as a 960x640 window of its own, so switching into *Manage Connections* made the
  same column visibly change size. Rows, icons and the filter box now match the schema tree exactly.
- **The sidebar header is the same control in both states.** A title on the left and one icon button on
  the right, at the same coordinates: a settings icon that opens connection management, and the × that
  leaves it again. *New connection* moved off the header down beside the filter, as the same small icon
  button the manage toolbar uses — so switching states no longer changes the shape of the column.
