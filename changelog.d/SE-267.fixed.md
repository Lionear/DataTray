- **A query tab opened from the tree now starts on that node's database.** "Select top 1000", the
  SQL command templates and "INSERT (with data)" opened their tab on the connection's default database
  (`master`) instead of the one the table lives in — visible in the database picker, and a real failure
  on engines that cannot reach across databases. New Query, reopening a file, duplicating a tab and
  Ctrl+Shift+T keep the database too, and switching a tab's connection no longer drops it while the
  new database list loads.
