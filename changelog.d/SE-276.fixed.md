- **Dates and numbers follow the operating system again, not the UI language.** Choosing English in
  *Settings › General* also switched every date, time and number to English formatting, so a result
  grid on a Dutch machine showed `12/2/2025 11:10:40 AM` instead of `2-12-2025 11:10:40`. The language
  setting now only changes the wording; the machine's regional settings decide how values are written.
