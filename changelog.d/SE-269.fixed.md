- **Typing a schema before the dot now narrows the completion list to that schema.** `SELECT * FROM
  [dbo].` offered every table in every schema — and `FROM dbo.` without brackets offered every
  *column* of every table, because the schema name was read as a table alias that resolved to
  nothing. A dot in FROM/JOIN is now understood as a schema qualifier, and `[dbo]`, `` `dbo` ``,
  `"dbo"` and bare `dbo` are all read the same way.
