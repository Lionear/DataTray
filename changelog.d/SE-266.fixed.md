- **"What's new" now actually shows what's new, and the Updates settings can start the download.** The
  release notes were never put into the update packages, so the dialog opened empty on every channel —
  stable included. They are now rendered once per build and embedded, so the notes on the release page
  and the ones the app shows are the same text. The Updates pane in Settings also gained a **Download
  Now** button beside *What's new*, with the progress and the install step alongside it, so an update
  can be taken without closing Settings to reach the banner.
