- **The tree's context menu no longer acts on the previously selected node.** Right-clicking the empty
  space below the last row left the old selection standing and opened the menu against it — so
  *Drop Schema…* could be confirmed for a schema you never clicked. A click that hits no node now
  clears the selection and opens no menu.
- **Drop and Alter dialogs name the database they will run against.** The confirmation used to show a
  bare `DataSync`, while `DROP SCHEMA [DataSync]` names no catalog of its own; it now reads
  `rick-test › DataSync`, so which database is about to lose the schema is visible before you confirm.
