- **Filter the connection tree from the sidebar.** A field under *Connections* narrows the tree while
  you type: connection names when everything is collapsed, and schema/table/view/column names inside
  whatever you have expanded. Non-matching rows are hidden rather than greyed out, the path down to a
  hit stays visible so you can see *where* it lives, and a footer line says how many of the loaded
  objects matched. `Esc` clears it and `Ctrl`/`Cmd`+`F` puts the caret in it (rebindable, under
  Settings ▸ Keyboard). It never expands a branch by itself — what you have not opened has not been
  fetched, and is therefore not searched. This is the counterpart to `Ctrl`/`Cmd`+`K`, which jumps to
  one object and closes again; the filter stays put.
- **Text in a single-line input sits centred again.** Every `TextBox` is a fixed 32px tall, but its
  content was anchored to the top, so the slack piled up underneath and the text read as sitting high —
  worst in the new sidebar filter, visible everywhere else. Multi-line boxes (SQL previews, cell values)
  keep their first line at the top, where it belongs.
- **The filter shows which part of a name it matched**, highlighted in the row, and the filter box keeps
  an accent ring while it is narrowing the tree so a partial tree never looks like the whole one. The
  search glyph and the clear cross now sit inside the field.
